# Neovim for Documentation

This project contains scripts and configuration files to install and configure Neovim for documentation writing.

## Prerequisites

This project installs all prerequisites automatically (superuser credentials necessary).

## Instructions

To install Neovim and set it up for documentation writing, run 

```
./install
```

To uninstall Neovim and remove all configuration files/directories, run

```
./uninstall
```
